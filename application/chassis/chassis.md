# chassis

## 双舵轮配置

底盘保留右前 `rf`、左后 `lb` 两组舵轮，轴距和轮距均为 344 mm，轮组安装位置关于底盘中心对称。

| 位置 | 驱动电机 M3508 | 转向电机 GM6020 | 舵向零位编码器值 |
| --- | --- | --- | --- |
| 右前 `rf` | CAN2 / ID3 | CAN2 / ID4 | 1325 |
| 左后 `lb` | CAN1 / ID1 | CAN1 / ID2 | 8169 |

## 工作流程

`ChassisInit()` 由 `RobotInit()` 调用。在底盘板上初始化两组舵轮共四台电机、底盘 IMU 和超级电容，并注册 `chassis_cmd` 订阅者和 `chassis_feed` 发布者。

操作系统启动后，底盘任务以 1 kHz 运行：

1. 从消息中心获取底盘控制命令。
2. 由两组舵轮反馈计算平移速度、角速度，并由 IMU 计算底盘倾斜状态。
3. 根据控制模式停止或使能四台电机，计算底盘旋转速度。
4. 处理云台与底盘偏转角前馈，将平移控制量映射到底盘坐标系，再进行速度插值、地形控制和加速度规划。
5. 计算右前、左后的舵向前馈，转换速度单位并进行双舵轮运动学解算，设置转向电机目标角度。
6. 更新超级电容控制和功率上限，设置两台驱动电机目标速度。`WheelPowerLimitCurrents()` 当前尚未接入电机输出链路。
7. 将底盘反馈发布到消息中心。

## 双轮速度观测

`ChassisSpeedMeasure()` 将驱动电机的有符号转子 RPM 换算为轮缘线速度（mm/s），再结合相对舵向零位取负号后的实际舵角，分解得到 `rf_vx`、`rf_vy`、`lb_vx`、`lb_vy`。

按照现有控制解算的符号，令 `h = CHASSIS_R * 0.70710678f`（约 172 mm）：

```c
raw_vx = (rf_vx + lb_vx) * 0.5f;
raw_vy = (rf_vy + lb_vy) * 0.5f;
raw_wz = (lb_vx - rf_vx + lb_vy - rf_vy) / (4.0f * h);
```

两轮的平移分量相同，旋转分量相反，因此取平均得到平移速度，取差得到角速度（rad/s）。驱动转速保留正负号，兼容舵角翻转 180 度后驱动反转的情况。

三项观测使用 20 点滑动平均，结果写入 `speed_measure` 和 `chassis_feedback_data`。`real_wz` 同时供大 Yaw 前馈、搜索补偿和底盘偏转角前馈使用。
